# Hangisi Daha? · Which Is More?

İki seçenek, tek soru: daha büyük, daha eski, daha kuzeyde?

Hızlı karşılaştırma turu: iki seçenekten doğru olanı çabuk seç. Ülke yüzölçümleri, il konumları, element kütleleri, gezegenler, olay tarihleri ve hayvan boyutları. Seri yaptıkça puan katlanır.

100.000 bölüm; her bölüm üretilir ve kurallara göre doğrulanır. Bilgi Yarışması merkez uygulamasının oyunu; ortak motor: [bilgi-motoru](https://github.com/taktemurr-ops/bilgi-motoru).
